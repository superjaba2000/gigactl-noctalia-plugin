# gigactl-noctalia-plugin

Плагин для [Noctalia Shell](https://github.com/noctalia-dev/noctalia-shell), позволяющий управлять профилями охлаждения и скоростью вентиляторов на ноутбуках Gigabyte с помощью утилиты [gigactl](https://github.com/smairio/gigactl).

## Возможности

- Переключение профилей охлаждения:
  - **Quiet** — тихий режим.
  - **Balanced** — сбалансированный режим.
  - **Performance** — производительный режим.
  - **MAX** — максимальное охлаждение.
- Ручное управление скоростью вентиляторов в режиме **Manual**

## Зависимости

### gigactl — обязательная зависимость

Для работы плагина необходима отдельно установленная утилита **gigactl**.

- Репозиторий: https://github.com/smairio/gigactl
- Должен быть установлен и запущен демон gigactl.
- Системная служба D-Bus должна быть доступна.

Плагин не управляет вентиляторами самостоятельно. Все операции управления оборудованием выполняются через gigactl.

**Перед установкой плагина необходимо установить и настроить gigactl.**

### Noctalia Shell

- Noctalia Shell 5.5.0 или новее.
- Plugin API 43.

## Использование

1. Установите и настройте [gigactl](https://github.com/smairio/gigactl).
2. Добавьте плагин gigactl-noctalia-plugin для Noctalia Shell с помощью ссылки на этот репозиторий.
3. Добавьте на свою панель виджет gigactl.

## Поддерживаемые устройства

Плагин предназначен для ноутбуков Gigabyte на платформе Clevo, поддерживаемых утилитой [gigactl](https://github.com/smairio/gigactl).

Совместимость плагина напрямую зависит от совместимости установленной версии gigactl с оборудованием.

**Перед установкой проверьте список поддерживаемых устройств:**

[ gigactl — Supported hardware ](https://github.com/smairio/gigactl#supported-hardware)

Обратите внимание на статусы устройств:
- Verified — проверено автором gigactl.
- Reported working — работоспособность подтверждена пользователями.
- Expected to work — предполагаемая совместимость, не проверенная на практике.

Установка и использование на неподдерживаемом оборудовании не гарантируются.
